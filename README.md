# Site d'enchère pour Lord Stampee

Un site d'enchères en ligne pour Lord Stampee, où les utilisateurs peuvent participer à des enchères en temps réel.

## Technologies Utilisées

- **Frontend**:
  - JavaScript
  - HTML
  - CSS

- **Backend**:
  - PHP (avec modèle MVC)
  - TWIG pour le templating
  - MySQL pour la base de données
